Client vs. Server Architecture:

When opening this website locally on my machine (by opening the index.html file directly in a web browser), a full client-server interaction does not occur. The web browser acts as a local client reading and rendering HTML and CSS files directly from the local file system, without sending HTTP requests to a remote web server over a network.
